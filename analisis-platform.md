# Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | C#, C++, dan bahasa .NET | Kotlin, Java, C++ |
| Arsitektur | Client-server. Browser bertindak sebagai client yang meminta sumber daya dari server | Aplikasi berjalan pada perangkat desktop dan dapat menggunakan model packaged atau unpackaged | Aplikasi terdiri dari beberapa komponen seperti Activity, Service, Broadcast Receiver, dan Content Provider |
| Cara distribusi | Diakses melalui web browser menggunakan URL | Microsoft Store, direct download, atau deployment perusahaan | Google Play dan distribusi aplikasi Android |
| Keunggulan | Mudah diakses melalui browser tanpa instalasi aplikasi khusus | Dapat memanfaatkan fitur sistem operasi serta memiliki pilihan packaging dan deployment | Praktis digunakan melalui perangkat mobile dan dapat memanfaatkan fitur perangkat |
| Keterbatasan | Untuk layanan online bergantung pada koneksi internet dan browser | Membutuhkan proses instalasi/deployment dan dapat bergantung pada sistem operasi | Bergantung pada perangkat dan sistem operasi serta aturan platform distribusi |
| Contoh aplikasi | Google Docs, YouTube | Microsoft Word, Visual Studio Code | WhatsApp, Instagram |
